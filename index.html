BTC Paper Agent Alerts

Operational failure and recovery notifications for a privately operated Bitcoin paper-trading agent.

What the app does

A private server checks the paper agent's scheduled jobs, market-data collection, session completion, and backups. This notifier sends operational failure and recovery emails to its owner's configured Gmail address.

The website is an information page only. It has no account registration, Google sign-in, trading dashboard, or access to the private agent.

Gmail access

The notifier requests only https://www.googleapis.com/auth/gmail.send so it can send email on the owner's behalf. It does not request permission to read the inbox, manage messages, access contacts, or delete mail.

Google authorization is completed privately by the owner. This website never collects passwords, authorization codes, or API keys.

Paper trading only

The agent currently simulates trades. The email notifier does not execute trades or provide investment recommendations. This site publishes no balances, trades, performance results, or private diagnostics.
